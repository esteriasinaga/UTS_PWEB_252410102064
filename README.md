# Smart Library

## Deskripsi Website
Smart Library merupakan website sederhana berbasis Laravel
yang dibuat untuk memenuhi tugas UTS mata kuliah
Pemrograman Berbasis Web.

Website ini memiliki tema pengelolaan perpustakaan untuk
menampilkan informasi koleksi buku dan data pengguna.

## Teknologi yang Digunakan
- PHP
- Laravel
- HTML
- CSS
- Blade Template

## Fitur Website
1. Login
2. Dashboard
3. Profile
4. Pengelolaan Buku
